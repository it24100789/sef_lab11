## Overview
This is the single-page frontend application for **CampusEats** scaffolded and configured for **Lab 11: DevOps and Cloud Hosting Platforms**.

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Production output is created inside `dist/`.

## Environment Variables
- `VITE_API_URL`: Points to the backend API root (e.g. `https://campuseats-api.onrender.com` or local `http://localhost:5000`).
